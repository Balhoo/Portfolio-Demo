FRONTEND / LOCAL-FIRST

Checkpoint

Una biblioteca de juegos con memoria: organiza pendientes, registra sesiones y conserva tu diario sin depender de una cuenta.

  • TypeScript
  • Vite
  • LocalStorage
  • Service Worker
Decisiones y alcance

Archivado recuperable, respaldos JSON validados y protección frente a conflictos entre pestañas. Caché offline tras la primera visita correcta. Pruebas y compilación automatizadas. Sin sincronización ni catálogo externo; el usuario necesita respaldar su biblioteca.

03

BACKEND / FULLSTACK / QA

ParcelPilot

Un laboratorio de distribución: asigna envíos, documenta incidencias y verifica cada transición hasta la entrega.

  • ASP.NET Core
  • SQLite
  • TypeScript
  • Playwright
Decisiones y evidencia

API con aislamiento por usuario, cookies HttpOnly y control de concurrencia. 12 pruebas unitarias, 31 comprobaciones HTTP y escenarios E2E en escritorio y móvil pasaron en CI. La demo es una simulación ficticia, sin cuentas, geolocalización ni transportistas conectados. El backend sigue siendo de laboratorio local.
